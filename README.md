# Prof. Kabiru Olusegun Akinyemi — Academic Portfolio

Official academic portfolio for **Professor Kabiru Olusegun Akinyemi**, Professor of Microbiology, Infectious & Zoonotic Diseases, and Director of Linkages, Partnerships & Collaborations at **Lagos State University (LASU)**.

Showcases research in molecular epidemiology and antimicrobial resistance, full publication library, teaching and supervision, honours and memberships, and full curriculum vitae.

---

## Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org) (App Router)
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** Hugeicons React

---

## Getting Started

Install dependencies:

```bash
pnpm install
```

Run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Other scripts

```bash
pnpm run build   # Production build
pnpm start       # Start production server
pnpm lint        # Run ESLint
```

---

## Project Structure

- **`app/`** — Routes and pages (home, about, research, teaching, publications, contact)
- **`components/`** — Layout (Navbar, Footer, Container), sections (Hero, About, Research, etc.), and UI components
- **`data/`** — Profile, research, and publications data (`profile.ts`, `research.ts`, `publications.ts`)

---

## Deploy

The app can be deployed on [Vercel](https://vercel.com), Netlify, or any platform that supports Next.js. For Vercel:

1. Push the repo to GitHub.
2. Import the project in [Vercel](https://vercel.com/new).
3. Deploy (default Next.js settings are sufficient).
